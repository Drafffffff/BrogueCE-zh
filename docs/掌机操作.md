# Brogue · RG34XX 按键指南

RG34XX / NextUI，720×480，纯手柄操作。

## 在地牢中

| 按键 | 动作 |
| --- | --- |
| 十字键 | 轻按走一步，按住连续移动；相邻两方向组合斜走 |
| A | 开始检查；检查中 A 仍使用当前原版前往行为 |
| B | 返回、取消或中断自动行动 |
| X | 背包 |
| Y | 搜索一次；按住反复搜索 |
| Start | 等待一回合 |
| L1 | 最近 500 条消息 |
| R1 | 角色与附近信息 |
| L2 | 行动页签 |
| Select | 地图全览 |
| R2＋方向 | 奔跑 |
| R2＋Y | 连续搜索 |
| R2＋Start | 休息恢复 |

轻按不会重复走。持续按住方向约三分之一秒后开始连走；松开即停。菜单、瞄准和警告等待会停止旧的长按动作，回到地牢后需要松开再按。自动行动用 B 中断。

## 行动页签

常用、物品、见闻、显示、本局五页签始终可见。上下选项，左右或 L1/R1 切签，L2/R2 上下页，A 执行，B 返回。

每签分别记住焦点和页位置，退出重开也会恢复。X 回常用并选中自动探索。页数显示在右下，翻页在首尾停止；上下选择可以连续越页。

保存在“本局”页的第一项，选择“保存并退出”，接受确认和存档名后离开。放弃、新开和特殊模式另列，并注明原版条件。

## 背包与物品

上下选择，A 打开物品操作页，X 直接读详情，L2/R2 翻页。取消或重开保留同一件物品；更名与装备重排时焦点跟随物品，物品消失后落在邻项。使用／装备等筛选列表与普通背包分别记忆，仅本次会话有效。短名称一行，长名称才留两行，分页按实际可见内容移动。文件列表同样使用紧凑间距。

物品操作一次列出所有适用动作。上下选动作，A 明确执行，B 回背包。R1 或“查看详情”读全文；全文上下滚动，L2/R2 翻页，B 回打开详情的位置。

药水的名称与符号使用本局外观色，地图上正常可见的药水也呈相同色相。颜色只表示外观，未知效果仍然未知。深色与黑色保持可辨亮度。

## 地图、瞄准与阅读

Select 打开全图，方向浏览，A 放大，X 回角色；B 从放大回全图，再 B 回地牢。检查／瞄准中方向轻按移动一格；长按稍作停顿后快速连移，松手即停，施放始终单独按 A 确认。Select 切换全图，X 切换原版可选目标，R1 看信息，A 确认，B 取消。打开窗口或取消瞄准后，旧长按不会接着移动角色。

L1 消息页保留本局最近 500 条真实归档，标题显示已有条数，每条标注回合编号，保留原颜色和重复次数。首次打开或新消息进入时落在最新处；上下回看，L2/R2 快速翻页，X 回最新，B 返回，L1 关闭。没有新消息时重开保留阅读位置。原版会合并重复消息，所以条数不等于行动次数；保存重载沿用原版重建方式，不能保证恢复会话中全部历史。

其他阅读页上下滚动，L2/R2 翻页，B 返回。字符输入中方向选字符、A 输入、X 删除、Start 完成、B 取消。默认存档名可以直接 Start 接受。

## R1 角色与附近

地图旁显示原版已经绘出的对象：相同符号、相同色相、生命比例、状态与行为。上下选择，L2/R2 翻页，地图标出当前对象。侧栏优先避开角色与目标，左右都拥挤时改用浅栏，地图字号保持不变。

A 阅读选中对象的已知侧栏信息；选择自己时可读完整营养、金币和全部状态。B 回到原处，R1 关闭。面板打开时相机不移动；X 明确定位当前对象，B 回原视野，再 B 返回地牢。检查／瞄准中打开时优先选中光标位置。

## 顶部与消息

第一行固定显示层数、深红生命条与生命值，右端显示当前模式。第二行合并力量、护甲、饥饿、潜行及异常；危险状态优先，放不下时以 +数量提醒。地图始终从同一高度开始，不因状态变化挪动。搜索提示在右上角，出现和消失不挪地图。完整营养、金币及状态从 R1 查看。

底部保留最近消息，L1 展开阅读。低生命与中毒警告沿用游戏的触发和暂停规则；需要确认的消息按 A/B 继续。

## 录像

Start 暂停／继续，左右逐回合，上下变速，X 背包，Y 全知，A 检查。L2 打开播放、跳转、见闻、显示、文件页签，切签与翻页规则相同；X 回播放首页。录像与游玩各自记忆位置。

本原型仍在完善：检查／前往分离及完整汉化接线还未完成。R1 当前展示原版侧栏可见信息，怪物的完整机制说明尚需补充入口。

标题页恢复原版动态火焰与 BROGUE 字标，中文选项位于底部。上下选择，A 确认，L2/R2 每次翻三项；从版本或难度选择返回时保留原焦点。
