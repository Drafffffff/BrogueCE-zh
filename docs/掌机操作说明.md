# Brogue · 掌机下一版按键指南

RG34XX / NextUI，已安装构建 `cbb61502`。网格背包、逐级返回、状态进度与光标详情。

## 在地牢中

| 按键 | 动作 |
| --- | --- |
| 十字键 | 轻按走一步，按住连续移动；相邻两方向组合斜走 |
| A | 开始检查；检查中 A 仍使用当前原版前往行为 |
| B | 返回、取消或中断自动行动 |
| X | 背包 |
| Y | 搜索一次；按住反复搜索 |
| ST | 等待一回合 |
| m（Menu） | 最近 500 条消息 |
| L2 | 附近浮窗依次左侧、右侧、关闭 |
| L1 | 行动页签 |
| R1 | 可交互角色与附近信息 |
| Select | 地图全览 |
| R2＋方向 | 奔跑 |
| R2＋X | 自动探索，B 中断 |
| R2＋Y | 连续搜索 |
| R2＋ST | 休息恢复 |

轻按不会重复走。持续按住方向约三分之一秒后开始连走；松开即停。菜单、瞄准和警告等待会停止旧的长按动作，回到地牢后需要松开再按。自动行动用 B 中断。

## 行动页签

常用、物品、见闻、显示、本局五页签始终可见。上下选项，左右或 L1/R1 切签，上下选项并自动滚动，A 执行，B 返回。

从 L1 打开的二级页面取消或阅读结束后，先回到原页签与选项；再按 B 才回地牢。完成消耗回合的行动后直接回地牢。

每签分别记住焦点和页位置，退出重开也会恢复。X 回常用并选中自动探索。页数显示在右下，翻页在首尾停止；上下选择可以连续越页。

保存在“本局”页的第一项，选择“保存并退出”，接受确认和存档名后离开。放弃、新开和特殊模式另列，并注明原版条件。

## 背包与物品

背包四列、26 格，一屏显示；方向键按行列选择，A 打开物品操作页，X 直接读详情。取消或重开保留同一件物品；更名与装备重排时焦点跟随物品，物品消失后落在邻项。使用／装备等筛选列表与普通背包分别记忆，仅本次会话有效。统一字号：名称一行，状态与数量一行；名称后有余地时显示原版力量需求 `<数值>`；名称过长时不追加。底部信息栏固定两行，第一行显示选中物品的已知名称与属性，第二行显示原版已知详情摘要；长文本省略，X 可读全文。横线与正文留出紧凑间距；按键提示紧接底部分隔线，移除其上的空行；信息栏与按键提示整体贴近屏幕下沿，最底部也不预留空行。文件列表继续使用紧凑间距。

物品操作一次列出所有适用动作。上下选动作，A 明确执行，B 回背包。选择“查看详情”读全文；全文上下滚动，L1/R1 翻页，B 回打开详情的位置。

药水的名称与符号使用本局外观色，地图上正常可见的药水也呈相同色相。颜色只表示外观，未知效果仍然未知。深色与黑色保持可辨亮度。

## 地图、瞄准与阅读

Select 打开全图，方向浏览，第一次 A 放大，再按 A 查看光标对象详情，X 回角色；B 从详情回原放大位置，再 B 回全图、再 B 回地牢。检查／瞄准中方向轻按移动一格；长按稍作停顿后快速连移，松手即停，施放始终单独按 A 确认。Select 切换全图，X 切换原版可选目标，R2 查看光标对象，进入悬浮栏后 A 看详情、B 逐层返回；瞄准中的 A 仍确认施放，B 取消。打开窗口或取消瞄准后，旧长按不会接着移动角色。

m 消息页保留本局最近 500 条真实归档，标题显示已有条数，每条标注回合编号，保留原颜色和重复次数。首次打开或新消息进入时落在最新处；上下回看，L1/R1 快速翻页，X 回最新，B 返回。没有新消息时重开保留阅读位置。原版会合并重复消息，所以条数不等于行动次数；保存重载沿用原版重建方式，不能保证恢复会话中全部历史。

其他阅读页上下滚动，L1/R1 翻页，B 返回。字符输入中方向选字符、A 输入、X 删除、ST 完成、B 取消。默认存档名可以直接 ST 接受。

## R2 角色与附近

固定 286 像素窄幅悬浮栏，只切换靠左或靠右，不扩展横贯全屏。地图旁显示原版已经绘出的对象：相同符号、相同色相、生命比例、状态与行为。上下选择，L1/R1 翻页，地图标出当前对象。侧栏优先避开角色与目标，左右都拥挤时改用浅栏，地图字号保持不变。

A 阅读选中对象的已知侧栏信息；选择自己时可读完整营养、金币和全部状态。B 返回。面板打开时相机不移动；X 明确定位当前对象，B 回原视野，再 B 返回地牢。检查／瞄准中打开时优先选中光标位置。

## 顶部与消息

第一行固定显示层数、深红生命条与生命值，右端显示当前模式。第二行合并力量、护甲、饥饿、潜行及异常；危险状态优先，放不下时以 +数量提醒。地图始终从同一高度开始，不因状态变化挪动。搜索提示在右上角，出现和消失不挪地图。完整营养、金币及状态从 R2 查看。

底部保留最近消息，m 展开阅读。低生命与中毒警告沿用游戏的触发和暂停规则；需要确认的消息按 A/B 继续。

## 录像

ST 暂停／继续，左右逐回合，上下变速，X 背包，Y 全知，A 检查。L1 打开播放、跳转、见闻、显示、文件页签，切签与翻页规则相同；X 回播放首页。录像与游玩各自记忆位置。

顶部仅显示最高优先级的一项效果与短进度条，其余用 +N 提醒。R2 选角色、A 查看全部效果的约剩余百分比与 ASCII 进度条；怪物／物品 A 查看原版已知详情，受可见性与幻觉限制。本原型仍在完善：检查／前往分离及完整汉化接线还未全部完成。

标题页恢复原版动态火焰与 BROGUE 字标，中文选项位于底部。上下选择，A 确认，L1/R1 每次翻三项；从版本或难度选择返回时保留原焦点。

附近摘要悬浮窗（已安装）：L2 在地牢中单独轻按，按左侧→右侧→关闭循环，使用独立 12px 字号和半透明深紫底，按原版侧栏顺序显示已知生物、道具和地形；生物保留生命比例与关键状态，总数在标题中显示，空间不足时提示剩余项并可用 R1 查看。窗口不改变地图字格或视野，也不接管移动按键。R1 打开可选择对象、定位与阅读详情的浮动栏。L1 打开行动菜单；m（Menu）单独轻按松开打开消息历史；m 与其他按键的系统组合不触发消息历史。所有阅读与列表用 L1/R1 翻页；行动菜单 L1/R1 切签，L2/R2 在菜单中不执行动作；背包不再提供肩键跨行。

浮窗渲染修正：附近摘要由平台在完整地图与 HUD 绘制完成后，单独调用屏幕空间叠加绘制；不写入 ASCII 格子、不参与地图尺寸计算。背景采用 alpha 160/255 的深紫色混合，文字与符号保持清晰。修正了旧背景辅助函数强制 alpha=255 导致不透明的问题。打开背包或全文阅读页时摘要暂时隐藏，返回地图后恢复。R1 交互栏与摘要可同时显示，双方根据选中对象和角色位置分居左右，避免相互覆盖。

L2 摘要只读，不设置焦点，也不拦截方向、确认或取消键；R1 交互栏负责选对象、定位和详情。两者同时出现时共享侧边位置判断，R1 在左则摘要在右，R1 在右则摘要在左。摘要字号 12px，背景 alpha 160/255，不要求与地图 ASCII 字格对齐。

本地修正：背包底部不再显示 L1/L2 跨行提示，跨行功能一并取消；分隔线使用独立 1px 虚线，与正文留出间距。物品完整详情仅保留顶部名称，移除原版正文开头带物品字母的重复名称段，后续说明和属性不变。

本轮汉化补查涵盖道具使用结果、混乱与麻痹等状态提示、解救被囚生物的确认及结果，以及法术反弹提示。保留原版 ASCII 字体与现有中文黑体；不采用候选像素字体。

肩键统一：L1/R1 在列表、历史、详情和对象栏翻页；行动菜单 L1/R1 切签，L2/R2 在菜单中不执行动作（左右方向键也可）。背包只用方向键选择。地牢 L2 单独轻按，附近浮窗依次左侧、右侧、关闭；组合键不改变浮窗。R1 对象栏始终位于摘要另一侧。
